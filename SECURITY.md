# Security Policy

`ghx` handles GitHub authentication tokens, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not** open a public issue for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/charlesreffett/github-cli-extended/security/advisories/new).
Include the steps to reproduce, the impact, and the `ghx`, `gh`, bash and OS versions involved.

You can expect an acknowledgement within a week. Fixes are released on the default branch, and
the advisory is published once a fix is available.

## Supported versions

Only the latest commit on the default branch is supported.
